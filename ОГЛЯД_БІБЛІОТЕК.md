# Огляд бібліотек для комп'ютерного бачення (Лабораторна робота №1)

## 1. OpenCV (Open Source Computer Vision Library)

**Призначення:** Бібліотека для реального часу комп'ютерного бачення та обробки зображень.

**Застосування в аналізі зображень:**
- Завантаження та збереження зображень у різних форматах (PNG, JPG, BMP тощо)
- Фільтрація та згладжування (Гаусів, медіанний фільтри)
- Детекція країв, контурів, особливих точок (SIFT, ORB, HOG)
- Сегментація (порогова, Watershed, GrabCut)
- Геометричні перетворення (масштабування, поворот, перспектива)
- Робота з відеопотоком та Optical Flow
- Інтеграція з глибоким навчанням (DNN модуль)

**Переваги:** Швидкість, велика кількість алгоритмів, підтримка C++/Python.

---

## 2. PIL / Pillow (Python Imaging Library)

**Призначення:** Бібліотека для відкриття, маніпуляції та збереження зображень у різних форматах.

**Застосування в аналізі зображень:**
- Читання та запис зображень (PNG, JPEG, BMP, GIF, TIFF)
- Базові операції: обрізання, поворот, зміна розміру
- Конвертація кольорових просторів (RGB, grayscale, HSV)
- Робота з метаданими (EXIF, розмір, режим)
- Підготовка даних для навчання нейромереж (аугментація через ImageEnhance)

**Переваги:** Простий API, підтримка багатьох форматів, зручна робота з файлами.

---

## 3. NumPy

**Призначення:** Бібліотека для чисельних обчислень з підтримкою багатовимірних масивів.

**Застосування в аналізі зображень:**
- Зображення як масиви (висота × ширина × канали)
- Векторизовані операції над пікселями (без циклів)
- Побудова гістограм, статистика (min, max, mean, std)
- Лінійна алгебра для перетворень та класифікації
- Підготовка тензорів для TensorFlow/PyTorch

**Переваги:** Швидкість за рахунок C-бекенду, сумісність з OpenCV та PIL (конвертація в/з ndarray).
