# Лабораторна робота №1 — Вступ до комп'ютерного бачення

**Варіант 1:** Розробка системи розпізнавання літаючих об'єктів.

## Зміст виконання

### Тиждень 1: Вступ до комп'ютерного бачення
- **Огляд бібліотек:** OpenCV, PIL, NumPy — опис та застосування в аналізі зображень (файл `ОГЛЯД_БІБЛІОТЕК.md`).
- **Модуль завантаження та відображення:** `image_loader.py` — завантаження зображень літальних об'єктів, відображення через OpenCV, підтримка PNG/JPG/BMP.

### Тиждень 2: Аналіз цифрових зображень
- **Завантаження та характеристики:** завантаження зображень у форматах PNG, JPG, BMP; виведення характеристик (розмір, канали, діапазон яскравості, середнє, стандартне відхилення).
- **Гістограма яскравості:** побудова гістограми (NumPy/OpenCV), візуалізація через matplotlib.
- **Покращення контрастності:** гістограмна еквіалізація, CLAHE, лінійна нормалізація — реалізовано в `histogram_contrast.py`.

## Файли проєкту

| Файл | Опис |
|------|------|
| `ОГЛЯД_БІБЛІОТЕК.md` | Огляд OpenCV, PIL, NumPy та їх застосування |
| `image_loader.py` | Модуль завантаження та відображення зображень |
| `histogram_contrast.py` | Гістограма яскравості та методи покращення контрастності |
| `lab1_main.py` | Головний скрипт для запуску лабораторної №1 |

## Запуск

1. Встановити залежності:
   ```bash
   pip install -r requirements.txt
   ```

2. Запустити з власним зображенням (PNG, JPG або BMP):
   ```bash
   python lab1_main.py шлях/до/зображення.png
   ```

3. Без графічних вікон (тільки збереження результатів у файли):
   ```bash
   python lab1_main.py шлях/до/зображення.png --no-gui
   ```

4. Показати список зображень у папці та їхні характеристики:
   ```bash
   python lab1_main.py --list папка/з/зображеннями
   ```

5. Без аргументів створюється тестове зображення і виконується повний цикл лабораторної.

Результати (гістограма та порівняння контрастності) зберігаються в `lab1_output/`.
